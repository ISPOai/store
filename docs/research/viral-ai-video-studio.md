# Viral AI Video Studio audience

**Researched:** 2026-09-01

**Purpose:** map the people, handoffs, commonly used software, open-source options, and current JavaScript/TypeScript Store opportunities for a studio producing short viral or campaign-oriented AI videos.

This is a detailed audience map within the broader [open-source app landscape](./open-source-app-landscape.md). “Commonly used” means representative software a working studio may use; it is not a claim that every studio uses every listed product. A role may use several products, an ordinary document editor, or no dedicated software.

The last column is intentionally stricter than the general open-source column:

- **READY / EXISTING:** a complete browser app, or an app already present in the Store.
- **BUILD UI:** useful JS/TS foundations exist, but ISPO would still need to build the product surface.
- **SERVER ONLY:** the project uses JS/TS but depends on a server, database, or infrastructure that is not a current iframe Store app.
- **GAP:** no suitable complete open-source JS/TS alternative was identified.

## API-backed workflow map

Commercial APIs are a separate solution category from the open-source applications above. They do not remove an open-source or JS/TS gap; instead, they let ISPO offer a small browser app whose interface and shared context live in the Store while generation, rendering, publishing, or data collection happens through a paid external service.

The most useful distinction is:

- **STRONG API FIT:** a focused Store app can cover most of this task through an official API.
- **HYBRID:** an API can automate a valuable part of the task, but a local editor or a person still completes it.
- **LIMITED / RESTRICTED:** useful endpoints exist, but access, platform policy, or the nature of the work prevents them from replacing the role.

| Role or stage | Official API options | What an ISPO mini-app or agent can do | Coverage and remaining work |
|---|---|---|---|
| **Producer / studio lead** | [Notion API](https://developers.notion.com/) or [Airtable Web API](https://airtable.com/developers/web/api/introduction). | Turn an approved brief into a production record, create shot rows and deadlines, and update status as artifacts arrive. | **HYBRID:** useful when a studio already uses one of these systems. Editor.js and Univer should remain the Store-native brief and schedule option. |
| **Trend strategist** | [YouTube Data API search](https://developers.google.com/youtube/v3/docs/search/list) and the limited-access [Google Trends API alpha](https://developers.google.com/search/apis/trends). TikTok's [Research API](https://developers.tiktok.com/products/research-api/) is for qualifying non-commercial research, not a normal commercial trend-discovery connector. | Search topics and recent videos, collect metadata, compare keyword interest, and attach candidate references to the brief. | **LIMITED / RESTRICTED:** YouTube can be supported; Google Trends requires alpha access; there is still no dependable commercial API for broad TikTok/Instagram creative intelligence. Human interpretation remains essential. |
| **Scriptwriter / hook writer** | [OpenAI Responses API](https://developers.openai.com/api/reference/resources/responses/methods/create), or equivalent official model APIs selected later. | Generate structured hooks, narration, calls to action, scene descriptions, and variants directly from the shared brief; return them as editable scene records rather than a chat transcript. | **STRONG API FIT:** Editor.js or BlockNote remains the human editing surface. A person should approve claims, tone, and final wording. |
| **Storyboard artist / shot planner** | A text-model API such as the [OpenAI Responses API](https://developers.openai.com/api/reference/resources/responses/methods/create), optionally followed by an image API. | Convert an approved script into validated shot JSON containing shot ID, duration, framing, camera motion, spoken line, generation prompt, and required assets. | **HYBRID:** the API creates the first shot plan; Excalidraw and Moodboard provide visual arrangement and human correction. |
| **AI art director / keyframe artist** | [Runway image generation](https://docs.dev.runwayml.com/guides/using-the-api/) or another reviewed image-generation API. | Generate keyframes and controlled variations from the style bible, attach provider/model/prompt metadata, and route candidates for approval. | **STRONG API FIT for generation; HYBRID overall:** visual consistency, brand taste, rights, and final retouching remain human/local-editor work. |
| **AI video artist** | [Runway API](https://docs.dev.runwayml.com/guides/using-the-api/), [Google Veo through the Gemini API](https://ai.google.dev/gemini-api/docs/video), or [Luma Dream Machine API](https://docs.lumalabs.ai/docs/api). | Submit text-to-video or image-to-video jobs for each approved shot, track queued/running/failed/completed state, receive the clip, and attach every take to its shot ID. | **STRONG API FIT:** this should be a provider-neutral generation app. Generation is asynchronous and potentially expensive, so it needs cost estimates, cancellation where supported, retries, and explicit take selection. |
| **Character / avatar animator** | [HeyGen Create Video API](https://developers.heygen.com/reference/create-video) or [Synthesia Create Video API](https://docs.synthesia.io/reference/create-video). | Render an approved avatar from a script or prerecorded audio, request the required aspect ratio, receive captions and video, and attach the result to the shot. | **STRONG API FIT:** identity and voice consent must be recorded before submission. | **Voice producer** | [ElevenLabs API](https://elevenlabs.io/api) for text to speech, speech to text, voice changing, and audio isolation; [Deepgram speech APIs](https://developers.deepgram.com/docs/stt/getting-started) are another possible provider. | Generate narration, create pronunciation variants, transcribe recorded speech, isolate dialogue, and return voice stems plus a transcript. | **STRONG API FIT:** AudioMass remains useful for manual trimming and cleanup. Voice cloning requires explicit consent and provider-policy checks. |
| **Composer / sound designer** | [ElevenLabs Music API](https://elevenlabs.io/docs/api-reference/music/compose) and [Sound Effects API](https://elevenlabs.io/docs/overview/capabilities/sound-effects). | Generate a timed instrumental bed, stinger, ambience, or individual sound effect from the brief; store the prompt, duration, provider, and output stem with the cut. | **STRONG API FIT:** this is a good thin Store app. Users still need to approve the result and confirm that their plan and use comply with the provider's current music/output terms. | **Motion designer** | [Creatomate Render API](https://creatomate.com/docs/api/reference/create-a-render) or [Shotstack Edit API](https://shotstack.io/docs/guide/architecting-an-application/guidelines/). | Fill a reusable branded template with titles, images, captions, logos, and calls to action, then render platform-specific video variants. | **HYBRID:** strong for repeatable templates and high-volume variants, not a substitute for a general motion-design interface or creative direction. |
| **Video editor / variant editor** | Creatomate or Shotstack for automatic assembly and rendering. | Assemble pre-approved assets from a timeline recipe, swap hooks, change aspect ratio, burn captions, and render batches. | **HYBRID:** API rendering is valuable for repeatable variants. | **Reviewer / brand-safety approver** | [OpenAI Moderation API](https://developers.openai.com/api/reference/resources/moderations) can pre-screen text and images; other media-safety APIs can be evaluated separately. | Check prompts, scripts, captions, and thumbnails before expensive generation or publishing, and create review flags tied to the exact artifact. | **LIMITED:** moderation is only a pre-screen. | **Localization and caption editor** | [ElevenLabs Dubbing API](https://elevenlabs.io/docs/eleven-api/guides/cookbooks/dubbing) plus a speech-to-text or translation API. | Transcribe the master, draft captions, translate approved dialogue, create dubbed variants, and attach SRT/VTT and audio/video outputs to each locale. | **STRONG API FIT for the draft:** names, timing, cultural adaptation, and final copy still need a fluent reviewer and a caption correction interface. |
| **Thumbnail / cover designer** | A reviewed image-generation API such as Runway's, followed by local image editing. | Generate cover concepts from the approved brief and selected frame, then produce platform-size variants. | **HYBRID:** miniPaint, SVG-Edit, or BitMappery should handle exact typography, crop, logo placement, and final export. |
| **Publisher / channel manager** | [YouTube Data API video upload](https://developers.google.com/youtube/v3/docs/videos/insert) and [TikTok Content Posting API](https://developers.tiktok.com/docs/en/content-posting-api-get-started). | Let a user connect an account, validate the release package, upload the final video and metadata, track processing, and return the public or private platform URL to shared context. | **STRONG API FIT with approval constraints:** both platforms require OAuth and policy compliance; unaudited API projects can be restricted to private posts. Publishing must require an explicit final user action rather than an unsupervised agent decision. |
| **Growth analyst** | [YouTube Analytics API](https://developers.google.com/youtube/analytics) initially; additional official platform analytics APIs can be added after access review. | Fetch authorized performance metrics, normalize them against release and variant IDs, and feed the results to Perspective, Vega-Lite, or Univer. | **STRONG API FIT for owned YouTube data:** other platforms and account types need separate approval and permissions. The analyst still interprets results and writes the next brief. |

### Recommended connector order

1. **First production bundle:** script and shot-plan generation; Runway or Veo video generation; ElevenLabs voice, music, sound effects, and dubbing; HeyGen or Synthesia avatars; YouTube publishing and analytics.
2. **Second bundle:** image/keyframe generation, Creatomate or Shotstack template rendering, and TikTok publishing after the app passes TikTok's review.
3. **Keep as explicit human/local stages:** cross-platform trend judgment, hands-on timeline editing, factual and rights review, consent verification, final approval, and performance interpretation.

ISPO should expose provider-neutral capabilities such as `script.generate`, `image.generate`, `video.generate`, `avatar.render`, `voice.generate`, `music.generate`, `sound-effect.generate`, `dub.generate`, `social.publish`, and `social.analytics.read`. This lets the workflow stay stable when a provider, model, price, or regional availability changes.

The Store iframe should never receive provider secrets or long-lived social OAuth tokens. A host-owned connector should submit the job, enforce per-user authorization and spending limits, receive a webhook or poll job status, copy the returned media into ISPO-controlled storage, and publish an artifact record containing the provider, model/version, request parameters, job ID, cost, consent/provenance fields, and associated shot or release ID.

## Shared-context handoff

The producer’s brief becomes the parent artifact. The strategist adds references; the scriptwriter creates scene versions; the storyboard artist assigns stable shot IDs; AI artists attach prompts, model metadata, and generated assets to those IDs; the editor records which takes entered each variant; review and localization attach decisions to the exact cut; and publishing returns platform URLs and performance data to the next brief.

The current Store can support much of the planning, storyboard, editing, audio, graphics, and local analysis path. Host-owned API connectors can fill most generation, dubbing, template-rendering, publishing, and owned-channel analytics gaps. Cross-platform trend intelligence, hands-on editing, rights and consent verification, factual review, final approval, and creative judgment remain genuine product or human-workflow gaps.
