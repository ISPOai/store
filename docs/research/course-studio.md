# Course Studio audience

**Researched:** 2026-09-01

**Purpose:** map the people, handoffs, commonly used software, open-source options, and current JavaScript/TypeScript Store opportunities for a team producing online courses, training modules, and supporting video lessons.

This is a detailed audience map within the broader [open-source app landscape](./open-source-app-landscape.md). “Commonly used” means representative software a course team may use; it is not a claim that every team uses every listed product. A role may use several products, an ordinary document editor, or no dedicated software.

The last column uses the same strict runtime boundary as the Viral AI Video Studio map:

- **READY / EXISTING:** a complete browser app, or an app already present in the Store.
- **READY CANDIDATE:** a complete JS/TS browser app that still needs packaging, CSP, dependency, license, and egress testing.
- **BUILD UI:** useful JS/TS foundations exist, but ISPO would still need to build the product surface.
- **SERVER ONLY:** the project uses JS/TS but depends on a server, database, or infrastructure that is not a current iframe Store app.
- **GAP:** no suitable complete open-source JS/TS alternative was identified.

## Shared-context handoff

The producer’s course brief becomes the parent artifact. Subject-matter sources and learning objectives attach to it; the scriptwriter and storyboard artist create stable lesson, screen, and shot IDs; media, assessments, captions, and slides attach to those IDs; QA approves a specific package version; publishing returns its LMS or public location; and learner performance becomes evidence for the next revision.

The current Store can support planning components, visual direction, diagrams, browser graphics, narration cleanup, video editing, slides, and local analysis. Lumi AI Editor is a promising narrow TypeScript candidate for interactive worksheets and H5P export. Complete course authoring, screen recording, formal review, LMS publishing, enrollment, learner records, certificates, and platform analytics remain gaps or server-backed systems.
